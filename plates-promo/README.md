# Plates — product film (v1)

Вертикальный ролик 1080×1920, 30 fps, 28,0 с. Монтаж на сетке **120 BPM** (доля 0,5 с, такт 2 с).

| Файл | Что это |
|---|---|
| `out/plates_promo_v1.mp4` | Ролик с sound design (без музыки), H.264 + AAC, −18 LUFS |
| `out/plates_promo_v1_silent.mp4` | Только картинка — для наложения трека в любом редакторе |
| `out/plates_sfx_stem.wav` | Дорожка эффектов отдельно |
| `out/beat_guide_120bpm.wav` | Метроном 120 BPM (акцент на каждом такте) — чтобы подобрать трек; в ролик не входит |
| `preview/key_*.png` | Ключевые кадры |
| `preview/privacy_sheet_2fps.jpg` | Все моменты ролика с шагом 0,5 с — проверка личных данных |

## Сильные доли (куда должен попасть удар трека)

0:03 reveal · 0:06 вход в интерфейс · 0:10 / 0:11 / 0:12 — 60 / 55 / 50 кг · 0:14 переход к прогрессу ·
0:18 начало монтажа · 0:22 финальный кадр · 0:25,5 логотип. Трек ставится первой долей такта на 0:00
(или вступлением бочки на 0:03).

## Пересборка

```bash
cd plates-promo
./src/export.sh <запись-экрана.mov> <логотип.png>
```

1. `src/prep_assets.py` — кадры записи, склейка прокрутки в длинные страницы, удаление статус-бара,
   веса тела и карточки «Вес тела»; экран настроек не используется вовсе.
2. `src/scene.html` — весь ролик как один детерминированный таймлайн (`render(t)`).
3. `src/render.js` — покадровый рендер в Chromium; `src/merge.py` — motion blur из подкадров.
4. `src/sfx.py` — синтез звуковых эффектов (без сэмплов и лицензий) и метроном.

Нужны: Python 3 + Pillow + numpy, Node.js + Playwright (Chromium), ffmpeg, ImageMagick.
Шрифт Inter Display (SIL OFL) лежит в `src/fonts/`.
