# Digital Journal — анимированные эмодзи для Telegram

Четыре значка для тем группы: **Навигация**, **Проекты**, **Своё дело**, **Личные заметки**.
Петли по 3,0 с, начало и конец совпадают.

| Папка | Что внутри |
|---|---|
| `tgs/` | Векторные TGS: 512×512, 60 fps, 180 кадров (3,0 с), только векторные фигуры, без растров и внешних ресурсов |
| `webm/` | Альтернатива: VP9 с прозрачностью (yuva420p), 100×100, 30 fps, 3,0 с, без аудио |
| `preview/` | `digital_journal_emoji_preview.gif` — превью на тёмном фоне с названиями; `check_24px_x4.png` — проверка при 24 px (увеличено ×4); `checks.txt` — результаты проверок |
| `src/` | Исходники (см. ниже) |

## Движения

- **Навигация** — корпус неподвижен; стрелка ищет направление: уходит на +44°, промахивается на −18°, корректирует +10° / −3° и встаёт на север.
- **Проекты** — документ поднимается из папки, на нём прорисовывается галочка, затем документ опускается обратно, и папка коротко «принимает» его.
- **Своё дело** — портфель приподнимается за ручку, покачивается с затуханием и опускается; ручка и застёжка реагируют с небольшой задержкой.
- **Личные заметки** — перо подходит к третьей строке, пишет её (линия рисуется ровно за кончиком пера) и возвращается; строка мягко исчезает перед новым циклом.

## Повторный экспорт

Нужны: Python 3 + Pillow + numpy, Node.js + Playwright с Chromium, ffmpeg с libvpx-vp9.

```bash
cd telegram-emoji
python3 src/export.py
```

Скрипт:
1. `src/build_tgs.py` — генерирует Lottie-анимации кодом и пишет `tgs/*.tgs` (gzip, `"tgs": 1`);
2. `src/render_frames.js` — рендерит **те же** данные плеером lottie-web (`src/vendor/`) в Chromium;
3. собирает WEBM, GIF-превью, лист проверки 24 px, `preview/checks.txt` и `digital_journal_emoji.zip`.

Только TGS: `python3 src/build_tgs.py`. Тайминг и амплитуды движений — ключевые кадры в функциях
`compass()`, `projects()`, `business()`, `notes()` в `src/build_tgs.py` (кадры при 60 fps).

## Публикация

Файлы для собственного набора эмодзи загружаются через бота @Stickers (`/newemojipack`).
GIF-превью — только для просмотра; в темах группы используются эмодзи из опубликованного набора.
